# MoodMix
A viral web app that helps users track their daily emotions through an interactive interface combining color psychology and music. Users pick a color that matches their mood, select or receive an AI-suggested song that resonates with that emotion, and build a beautiful visual + musical diary over time.

Key Features:
- Interactive color wheel emotion selector
- Daily mood tracking with color visualization
- Music suggestions based on mood
- Shareable weekly mood boards
- Progressive Web App support

Tech Stack:
- HTML5 Canvas for color wheel
- Web Audio API for music preview
- LocalStorage for data persistence
- Responsive design
